
# MSc Robotics – Academic Project Portfolio

University of Birmingham | MSc Robotics | 2025–2026

## Overview

This repository showcases selected engineering projects and research completed during my MSc Robotics at the University of Birmingham.

The projects cover autonomous mobile robotics, computer vision, robotic manipulation, mathematical modelling, control systems and industrial automation, combining theoretical engineering principles with practical implementation and validation.

## Projects

| Project | Technical Focus | Tools |
|---|---|---|
| [Intelligent Book Retrieval Robot](./intelligent-book-retrieval-robot) | Odometry, localisation and occupancy mapping | Python, Webots |
| [Vision-Guided Robotic Fruit Sorting](./vision-guided-robotic-fruit-sorting) | Object detection, visual servoing and robotic manipulation | Python, YOLOv8, OpenCV, Quanser QArm |
| [Quanser Aero 2 – PID and LQR Control](./quanser-aero2-pid-lqr-control) | Dynamic modelling, state-space control and model validation | MATLAB, Simulink, QLabs, QUARC |
| [Factory-in-a-Box: Automated XY Stage Assembly](./factory-in-a-box-robotic-assembly) | Industrial robotics, digital twins and assembly optimisation | RoboDK, CAD, KUKA |
